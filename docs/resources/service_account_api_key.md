# opencodecontrols_service_account_api_key (Resource)

Manage one OpenCode Console service account API key. Terraform stores the one-time value for newly issued keys in state. Import brings existing key metadata under management without rotating the key.

Changes to the name, scopes, permissions, or expiration replace the key.
Destroy revokes the key. Use `prevent_destroy` for adopted production keys
until you have planned how their consumers will switch to a replacement.

Supply scope names accepted by OpenCode Console, such as `models:read`.
The management key must have every scope it delegates.

```terraform
resource "opencodecontrols_service_account_api_key" "models" {
  service_account_id = "svcacct_01AAAAAAAAAAAAAAAAAAAAAAAA"
  name               = "model-catalog"
  scopes             = ["models:read"]
}
```

## Import

Use an import block or `terraform import` with
`SERVICE_ACCOUNT_ID/API_KEY_ID`. Use the existing name, scopes and expiry
when configuring the resource. For a UTC expiration, use Z and omit trailing
zero fractional seconds. Keep using the original secret store for the
bearer token. The `value` attribute is populated only when Terraform issues
the key.

```shell
terraform import opencodecontrols_service_account_api_key.models svcacct_01AAAAAAAAAAAAAAAAAAAAAAAA/sk_11111111-1111-4111-8111-111111111111
```

## Schema

### Required

- `name` (String) Name shown in the service account's credentials list. Changing this replaces the key.
- `service_account_id` (String) OpenCode Console service account ID, beginning with svcacct_.

### Optional

- `expires_at` (String) Expiration as an RFC3339 timestamp with whole-second precision. Omit for a key without expiration. Changing this replaces the key.
- `permissions` (String) Permission level. New keys must be restricted (the default). Import can preserve all or read-only keys.
- `scopes` (Set of String) Permission scopes, such as models:read. Specify at least one scope when creating a key. Changing this replaces the key.

### Read-Only

- `id` (String) OpenCode Console API key ID, beginning with sk_.
- `status` (String) Status reported by OpenCode Console.
- `value` (String, Sensitive) Bearer token returned at creation. Terraform stores it in state. Imported keys have no value in state.

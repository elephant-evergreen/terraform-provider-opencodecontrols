# OpenCode Controls Provider

Manage OpenCode Console service account API keys.

This community provider is an opt-in alpha. It uses OpenCode Console API
routes for which OpenCode does not publish a versioned reference.

In OpenCode Console, open the service account and add a restricted management
key. Set **Service accounts** to **Read**, **This account's API keys** to
**Write**, and include the scopes you want to grant to keys Terraform issues.
For example, include **Models: Read** to issue a key that can list models.
Use a different key for your workloads. See the
[OpenCode Console API overview](https://opencode.ai/docs/console/api/).

Set `OPENCODE_CONTROLS_API_KEY` in the Terraform process environment. Run
`terraform init` with the exact version, add the resource you want to manage,
and review `terraform plan` before applying.

```terraform
terraform {
  required_providers {
    opencodecontrols = {
      source  = "elephant-evergreen/opencodecontrols"
      version = "= 0.0.1-alpha.1"
    }
  }
}

provider "opencodecontrols" {}
```

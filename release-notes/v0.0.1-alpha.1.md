## Upgrade notes

This is the initial opt-in release. Pin `= 0.0.1-alpha.1` to select it.

- Manage OpenCode Console service account keys with restricted scopes.
- Read key metadata as a list or import a key by service account ID and key ID.
- Preserve imported key values in their existing secret stores. New key values
  are sensitive Terraform state.
- Use a Console-issued management key. This alpha depends on Console API routes
  for which OpenCode does not publish a versioned reference.
- Use whole seconds for expiration timestamps. OpenCode rounds fractional
  seconds, which would trigger a replacement on the next plan.
